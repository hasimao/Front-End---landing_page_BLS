# Landing Page: Stronger Than Death Night

Landing page de um evento fictício em homenagem ao álbum *Stronger Than Death* (2000), da banda Black Label Society. Trabalho prático de HTML e CSS.

## Tecnologias
- HTML5 semântico
- CSS3 (Flexbox e CSS Grid)

## Requisitos do trabalho
- **Semântica:** uso de `header`, `nav`, `main`, `section`, `article`, `figure` e `footer`.
- **Posicionamento:** Flexbox no cabeçalho, no destaque, nas dúvidas, na inscrição e no rodapé. Grid no "Sobre", no repertório e nos ingressos.
- **Estilização:** paleta preta com vermelho, fontes, margens e paddings, e layout adaptado para celular.

## Como visualizar
Baixe o repositório e abra o arquivo `index.html` no navegador.
